# Plain-language communication

Use this skill when writing or reviewing text for a person, an agent, or this repository.

## Choose the language

- Follow the user's language for Dutch and English conversations.
- Use Dutch when the language is mixed or unclear.
- Follow an explicit request for an output language.
- This skill does not change behavior for a clear language other than Dutch or English.
- Use plain English for new or changed repository documentation.

## Write for the reader

Before writing, identify the user, task and context when they are known or needed. Write so readers can:

- get the relevant information;
- find the information they need;
- understand what they find; and
- use the information to act or decide.

Use short, direct sentences and useful headings, but do not remove information that is needed for a correct decision. Keep technical terms, code, commands, identifiers and quotations when changing them would reduce precision. Explain a necessary term the first time it appears.

## Review and improve

Check the result against relevance, findability (make the needed information findable), understandable wording and usability so the result is usable. Use feedback from the user to correct language, structure or assumptions, then improve the text iteratively. Ask a focused question when missing context could change the result.

These practices are informed by ISO 24495-1:2023 and ISO 9241-210:2019. Do not claim ISO certification or full compliance based on this skill or on public summaries of those standards.
